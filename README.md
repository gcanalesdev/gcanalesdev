# Hi, I'm Gabriela 👋

**QA Engineer | ISTQB CTFL certified** — 3+ years testing critical enterprise projects in the energy sector (Naturgy, Iberdrola).

I started as a **back-end developer**, so I know what it's like on the other side of the bug report — and I write mine accordingly.

---

### 🔭 What I'm working on

**[ortal](https://github.com/gcanalesdev/ortal)** — my Project Zomboid playground: mods, Spanish translations, and a Python localization pipeline called *esbrus*.

What started as translating mods by hand became a testing challenge: too many repetitive manual checks, so I'm building the tool that automates them.

### 💼 A bit of my story

I discovered testing during a traineeship at Hiberus, got my **ISTQB CTFL** certification there, and since 2023 I've been a QA Engineer at Viewnext:

- 🔌 At **Naturgy** I did functional and front-end testing, and trained teammates on testing best practices
- 📱 At **Iberdrola** I test **REST APIs and mobile apps** — I'm the technical referent for QA and dev teams, helping solve doubts and debugging batches
- 🔐 I led the **QA lane of an internal database restructuring project**, making sure encryption and security measures were properly implemented
- 💻 Before all that, I spent a year as a back-end developer (**PHP, SQL, MySQL, JavaScript, Bootstrap**) — reading code and talking to developers has never been a problem for me

**Where I'm heading:** Test Automation Engineer — building my Python automation skills project by project (you're looking at one of them 👆).
